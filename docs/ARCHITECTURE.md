# Архитектура

`PCD/PLY/XYZ/CSV или ROS 2 bag/PointCloud2 → XYZ/ring → геометрия пола и рельсов → траектория габарита → кластеры → проверка соседних лучей → single/confirmed → JSON + панель`

- `sources.py`, `io.py`: файлы и декодирование PointCloud2, включая endian, stride/padding. Неподдерживаемый формат даёт явную ошибку.
- `detector.py`: преобразование осей, фильтр невалидных/нулевых точек, настраиваемые маски своего поезда, выделение ROI, связные воксели, критерии поддержки и временное подтверждение.
- `rails.py`, `tunnel.py`, `trajectory.py`: ближняя опора по рельсам и продолжение по геометрии тоннеля. На неоднозначной геометрии растёт неопределённость; на разветвлениях и без калибровки нельзя гарантировать выбор собственного пути.
- `surfaces.py`, `range_context.py`: отсечение протяжённых поверхностей и проверка угловой связности с контекстом полного облака. Критерий соседних лучей основан на опубликованной идее Depth Clustering; реализация собственная, нейросетевых весов нет.
- `streaming.py`: один вычислительный поток, очередь последнего кадра; отдельный ROS executor с собственным контекстом. `ros_node.py` — запуск без интерфейса.
- `server.py`, `history.py`: HTTP, SQLite-журнал тревожных кадров и оценки оператора.
- `web/`: локальные Three.js/OrbitControls, облако и рамки, история, подключение, демонстрационный маршрут.

Карта, ручная разметка, имена файлов и номера кадров **не участвуют в решении детектора**. Офлайн работа не обращается к интернету. Основные вычисления — NumPy/SciPy на CPU; GPU используется браузером для рисования, CUDA не требуется.

Источники: [Depth Clustering](https://github.com/PRBonn/depth_clustering), [статья IROS 2016](https://www.ipb.uni-bonn.de/pdfs/bogoslavskyi16iros.pdf), [ROS 2 Humble launch](https://docs.ros.org/en/ros2_documentation/humble/How-To-Guides/Launch-file-different-formats.html), [Hesai ROS 2 driver](https://github.com/HesaiTechnology/HesaiLidar_ROS_2.0). В поставку не включены чужие датасеты, драйвер Hesai или модели.

## Проверка траектории на поворотах (0.4.2)

Когда маршрут следует одной стене, неопределённость учитывает полное расхождение с другой стеной. Независимая привязка стен на 8–20 м проверяет дальнюю пару рельсов даже внутри диапазона её аппроксимации. Для участка до первой измеренной пары сравниваются глобальная кривая и продолжение ближайших измерений. Расхождение расширяет область неопределённости; тревога требует достаточных точек внутри устойчивой части габарита. Ненадёжная геометрия остаётся UNCERTAIN, а не сообщением о свободном пути. Номера кадров, названия проездов и пользовательские оценки не используются.
