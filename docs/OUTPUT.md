# Выход детектора

Офлайн: одна строка JSON на входной кадр, UTF-8 (`--output detections.jsonl`). ROS 2: JSON в `std_msgs/msg/String`, топик `/metro/obstacles`. Частота результата соответствует обработанным кадрам, а не гарантированным 10 Гц.

| Поле | Значение |
|---|---|
| schema_version | 1 |
| status | OBSTACLE / UNCERTAIN / NO_OBSTACLE_DETECTED |
| obstacle | true, если есть поддержанный кандидат в габарите и выполнен выбранный режим подтверждения |
| distance_m | Минимальное евклидово расстояние от исходного лидара до точек тревожного объекта; null без тревоги |
| candidate_distance_m | Ближайший кандидат, включая неопределённые; не является подтверждённой тревогой |
| objects | Кандидаты: min, max, center, dimensions, points, supported, confirmed, evidence |
| nearby_objects | Кластеры вне габарита, отдельные от тревоги |
| timestamp_ns | В bag — время сообщения в записи, ROS — header.stamp; для облака без времени может быть null |
| basis_raw_to_forward_left_up | Матрица преобразования исходных XYZ в координаты детектора |
| processing_ms | Время алгоритма, без чтения, передачи и рисования |
| queue_and_processing_ms | Для потока: ожидание после декодирования + вычисление |
| source | Метаданные входа и, для потока, сессия/конфигурация |
| warnings | Неподтверждённая калибровка, неизвестная геометрия, разреженность и др. |

Внутренние координаты объектов: X вперёд, Y влево, Z вверх, метры. `raw_center` — исходные XYZ лидара. Размеры вычисляются вдоль внутренних осей; это осевые боксы, не ориентированные по объекту. Confidence — эвристика, **не калиброванная вероятность**. Тип объекта не классифицируется.

**obstacle=false при UNCERTAIN не означает, что путь свободен.** NO_OBSTACLE_DETECTED также означает отсутствие обнаруженного объекта, а не гарантию безопасности. Проверяющий должен учитывать status и warnings, а не только bool.

Режим single: достаточно одного облака. confirmed: поддержанный объект сопоставляется по пространственному окну в 2 из 3 кадров по умолчанию. Это кратковременное подтверждение, а не полное отслеживание с одометрией. Перестановка времён или большой разрыв сбрасывает историю.

В онлайн-режиме очередь содержит максимум один ожидающий кадр; поступивший новый кадр заменяет устаревший. `/api/live/status` показывает received/processed/dropped. `process` последовательно обрабатывает все кадры и не сбрасывает их ради скорости.
