Скачать подробный отчёт проверки

История накапливается при просмотре облаков и обработке подключённого потока. Повторный просмотр того же результата не создаёт дубль. Считаются кадры, а не уникальные физические препятствия.

Проверка за несколько шагов

Один алгоритм для файла, записи и PointCloud2 от лидара. Интернет во время работы не нужен.

01

Загрузить облако

Во вкладке «Обнаружение» нажмите «Загрузить облако». Поддерживаются PCD (binary / ASCII), PLY, XYZ и CSV с полями x,y,z. Единицы — метры.

Результат и облако появятся вместе. Оси по умолчанию: −Y вперёд, +Z вверх. Для другого монтажа загрузите конфигурацию или задайте оси перед проверкой.

python -m metro_detector process scan.ply \
  --output detections.jsonl
02

Воспроизвести ROS 2 bag

Выберите «Bag / поток ROS 2», укажите путь внутри подключённой папки /data. Нажмите «Найти топики», выберите PointCloud2 и подключите запись. Поддерживаются папки bag, .db3 и .mcap.

docker run --rm -p 8190:8190 \
  -v /path/to/data:/data:ro \
  -v /path/to/output:/output \
  metro-detector serve --data /data \
  --state /output/state --host 0.0.0.0

Воспроизведение в панели показывает актуальный кадр. Для обработки каждого кадра без пропусков используйте команду process.

03

Подключить физический лидар

Запустите драйвер производителя, публикующий sensor_msgs/msg/PointCloud2. Для Hesai используйте официальный драйвер и калибровку конкретного датчика. Затем выберите ROS 2 в панели и введите топик.

ros2 topic list -t
ros2 topic hz /lidar_points
# Linux, та же сеть DDS и ROS_DOMAIN_ID:
docker run --rm --network host \
  -v /path/to/output:/output \
  metro-detector serve --host 0.0.0.0 \
  --state /output/state

Прямые UDP-пакеты датчика не являются PointCloud2: их декодирует драйвер. При отсутствии ROS 2 панель объяснит, как запустить Humble-контейнер.

04

Проверить результат

Красная рамка — тревога. Синяя — кластер рядом с расчётным путём. Янтарный статус — недостаточно данных; он не означает «путь свободен».

ros2 topic echo /metro/obstacles
# Обработать все сообщения bag:
docker run --rm -v /bag:/data:ro \
  -v /output:/output metro-detector \
  process /data --bag \
  --output /output/detections.jsonl

История сохраняет тревожные кадры. Карта во второй вкладке — наглядная демонстрация, а не локализация по данным лидара.

Калибровка, дальность 150+ м и пропуски должны проверяться отдельно. Низкое число тревог само по себе не доказывает качество обнаружения.
