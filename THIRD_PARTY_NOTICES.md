# Сторонние компоненты

- В `web/vendor` включены Three.js и OrbitControls. Их MIT-лицензия сохранена в `web/vendor/LICENSE.three.txt`.
- Python-зависимости устанавливаются из `requirements.txt`; версии контейнера закреплены в `requirements-container.txt`. NumPy, SciPy, rosbags и plyfile сохраняют собственные лицензии.
- Docker использует официальный образ ROS 2 Humble на Ubuntu 22.04. Компоненты образа распространяются по своим лицензиям.
- Проверка угловой связности использует опубликованную идею Depth Clustering (Bogoslavskyi & Stachniss, IROS 2016); реализация в `range_context.py` собственная. Код проекта PRBonn не скопирован.
- Драйвер Hesai, исходные датасеты, веса нейросетей и сторонние карты не включены в репозиторий.

Лицензия на собственный код проекта владельцем пока не выбрана. MIT-файл Three.js относится только к соответствующему стороннему компоненту.
